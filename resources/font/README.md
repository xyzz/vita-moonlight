# UI font

`font.ttf` is a static subset of Noto Sans CJK TC 2.004 from
[notofonts/noto-cjk](https://github.com/notofonts/noto-cjk).

Source revision: `f8d157532fbfaeda587e826d4cd5b21a49186f7c`
Source file: `Sans/Variable/TTF/NotoSansCJKtc-VF.ttf`
Source SHA-256: `6B40DD16CF1B73B5A7A0ED2472D641B60E3E85E87211ABD20009F67D841425DA`
Subset SHA-256: `5123D6D3CCB86B6ADB5D48260E2F71D90EA0D55924F075B60F2C3704730E8376`

The variable font was instantiated at weight 400 and subset to preserve every
Unicode character that the previous Moonlight Vita UI font exposed when Noto
provides it, plus all characters currently used by the bundled translations and
the standard controller symbols used by Vita hints.
